# 待办栏（1.0.30）

左侧待办和右侧日历是绑定窗口：一起展开、收起、移动和锁定，上下边缘对齐，高度同步。左栏仅左边缘支持调宽，宽度保存在本地设置中。左右各保留自己的原生毛玻璃背景和系统圆角。右上角浏览器图标通过系统默认浏览器打开 Google 日历。

## 连接 Google Tasks

1. 在 Google Cloud 控制台中，选择日历应用 OAuth 客户端所属的项目。
2. 打开「API 和服务 → 库」，搜索 **Google Tasks API** 并启用。
3. 在 Google Auth Platform 的「数据访问」中加入 `https://www.googleapis.com/auth/tasks` 权限。测试状态下，使用者仍需在该项目的测试用户列表内。
4. 启动新版，在左栏点击「连接 Google Tasks」，在浏览器中完成补充授权。首次登录同时申请日历和 Tasks 权限。

任务清单、标题、备注、日期、完成状态通过 Google Tasks 官方 API 双向同步。有安排日期的任务可在 Google 日历中显示，需在 Google 日历中勾选 Tasks。无日期任务保留在任务清单内。官方 Tasks API 目前不支持读取或写入任务的具体时刻，因此此版本只提供日期选择。

## 操作

- 顶部下拉框选择 Google 任务清单。
- 「添加待办」和右上角加号打开新增表单。
- 点击标题编辑标题、日期、备注或删除，删除前需要确认。
- 点击圆圈完成或恢复任务；完成任务放在「已完成」折叠区。
- 左栏无刷新按钮和正常同步状态；沿用日历右下角刷新及已有节电同步调度。只有请求失败时显示错误说明。
- 本地任务缓存使用 Windows 当前用户 DPAPI 加密；断开账号后清除任务缓存。

## 验证范围

新增的接口测试覆盖清单/任务分页、完成状态、日期时区语义、版本冲突、删除幂等、API 未启用及旧账号权限不足。窗口测试覆盖对齐、双方高度调整、左栏宽度调整、共同锁定、原生材质外框、同步收起和浏览器按钮。总计 295 项检查通过。Google 账号的实际在线授权和读写需要启用 Tasks API 后验证，测试未修改真实账号的任务。
