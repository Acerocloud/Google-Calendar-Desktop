# Google 登录

此版本已内置桌面 OAuth 配置，无需导入 JSON。

1. 打开设置，点击「登录 Google」。
2. 在系统浏览器里选择账号，允许读取日程和日历列表。
3. 登录完成后返回软件，等待同步。
4. 在设置中选择显示的日历。

首次授权仍需本人确认；软件不接收 Google 密码。令牌使用 Windows DPAPI 加密保存在本机。

如果提示 access_denied，且应用仍处于测试状态，请维护者在 Google Auth Platform → Audience 中把登录邮箱加入测试用户。
测试状态下日历授权及刷新令牌有效期为 7 天，到期需重新登录。公开分发需处理生产配置及相应验证。

升级前从系统托盘菜单退出旧版。现有客户端和登录状态继续使用；更换目录后重新设置开机启动。

要更换已有客户端，请先断开账号并退出，再备份并移除 %LOCALAPPDATA%\DeskCalendar\client.bin，重新启动后使用内置客户端。不要单独移除仍在使用的账号对应客户端。
断开账号：设置中点击「断开账号」，本机令牌和日程缓存立即清除。不会自动打开登录页。
退出组件：右下角托盘图标右键 → 退出。

1.0.5：启动后单击右下角托盘图标展开日历；点击外部、再次单击或按 Esc 收起。只有托盘菜单退出才结束程序。
